# مدار — Mdaar21

**[افتح مركز مدار — كل الروابط والملفات ومكان التعديل](MDAAR_HUB.md)**

المركز هو مرجع المالك والمطوّر لتحديد الجزء المقصود عند كل تعديل: **المتجر، الواجهة، التطبيق، صفحة المنتج، الكتاب**. يحتوي الروابط الحالية وملف الكتاب ومصادر التعديل.

## المصادر الحالية

| الجزء | المصدر |
| --- | --- |
| تطبيق الحاسبة والوجبات والتمارين | [public/](public/) |
| الواجهة التعريفية | [public/discover/](public/discover/) |
| كتاب بروتوكول التحول | [دليل الكتاب](docs/book/README.md) و[scripts/build-book.py](scripts/build-book.py) |
| خدمة اسأل مدار | [Cloudflare Worker](cloudflare/worker.mjs) و[تعليمات التشغيل](docs/github-ai.md) |
| المتجر وصفحة المنتج | إعدادات خارجية في زد؛ روابطها في [المركز](MDAAR_HUB.md) |

المستودع الحالي `mdaar21/Mdaar21`. المصادر في `main`، وموقع GitHub Pages في `gh-pages`. الحالة الحالية وروابطها مقدّمة في مركز مدار؛ تقارير الحسابات السابقة وNetlify توثّق تاريخها.

## التشغيل المحلي

يتطلب Node.js 22 أو أحدث:

```sh
npm ci --ignore-scripts
npm run dev
```

يفتح خادم التطبيق المحلي على المنفذ 4173. أدوات الغذاء والتدريب محلية؛ الاتصال بالمزود يحتاج إعداد الخدمة. لا تضف أسرار الإنتاج إلى Git أو ملفات الواجهة.

## التحقق والبناء

```sh
npm run check
npm test
npm run test:browser
npm run test:a11y
```

اختبارات المتصفح تحتاج Chromium؛ استخدم `CHROMIUM_PATH` عند الحاجة. [إعداد Pages وCloudflare](docs/github-ai.md) و[إعادة تصدير الكتاب](docs/book/README.md).

الهوية: أسود وذهبي دافئ وعاجي، مع العربية وRTL. تحفظ أغلفة مدار وشعارها الأصلية. بيانات الطعام والوزن والتدريب تُحفظ في متصفح المستخدم، ويمكنه تصديرها أو حذفها. القيم الغذائية تقديرية. تحديث ملفات المشروع لا يغيّر منتج زد أو تسليمه تلقائيًا.
