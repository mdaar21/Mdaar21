- بروتوكول التحول بسعر **15.99 ريال**، مع رابط الشراء الحالي على زد: https://mdaar21.zid.store/products/بروتوكول-التحول . السعر ثابت في الواجهة ولا يغيّر سعر زد.
- صفحة البروتوكول التفصيلية السابقة محفوظة في `protocol.html`، وتستعمل `assets/discover.css` و`assets/discover.mjs` ومعاينات الكتاب الأصلية. شعار رأسها يعيد إلى واجهة المنتجات.
- جيب العشرة بسعر **10.99 ريال**؛ تُعرض كمنتج عادي دون «قريبًا». زر «تفاصيل اللعبة» يقود إلى قسمها داخل الصفحة. لا رابط شراء أو تشغيل أو تضمين للعبة في الواجهة، بناء على توجيه المالك إلى حين تزويد رابط البيع.
- عرض جيب العشرة يخص لعبة القوائم العشر فقط: 500 فئة، طور فردي أو فريق ضد فريق على الجهاز نفسه، عشر إجابات وخمس أخطاء. لا تسويق لأي لعبة ثانية أو جمعها في حزمة. الرسم معاينة توضيحية ثابتة، وليس لعبة قابلة للتشغيل.

## الأصول والحدود

الخط IBM Plex Sans Arabic محلي، مع ترخيصه في `assets/FONT-LICENSE.txt`. غلاف الكتاب وشعار مدار من الأصول الأصلية. صفحة البروتوكول تعرض عينات مختارة دون رابط عام لتنزيل الكتاب الكامل. لا تقييمات أو أرقام مبيعات أو ضمانات نتائج مختلقة.

لم تتغير ملفات تطبيق مدار أو الكتاب أو لعبة جيب العشرة، ولا إعدادات الدفع والتسليم في زد. كل روابط المنتجات والتنقل والأسئلة تعمل دون JavaScript، والحركة تراعي `prefers-reduced-motion`.

## البناء والتحقق

ابنِ النسخة المنشورة باستخدام:

```sh
python3 scripts/build-github-pages.py --output /path/outside/repo --base /Mdaar21/
```

يظل `main` مصدر الملفات و`gh-pages` شجرة النشر. تُنشر ملفات الواجهة المولّدة فقط مع الحفاظ على التطبيق الموجود. لا تستبدل شجرة النشر بمصدر HTML غير معالج.

التحقق الموجّه: `npm run check`، `npm run test:analytics`، ثم فحص المتصفح على الجوال وسطح المكتب للروابط الداخلية، رابط الشراء، صفحة البروتوكول ومعاينتها، الأسئلة، لوحة المفاتيح، التباين، غياب التمرير الأفقي، ونسخة دون JavaScript. تقرير الواجهة الجديدة: `docs/reports/storefront-validation.json`. لم يُختبر شراء فعلي أو تسليم عبر زد.

حزمة `docs/artifacts/mdaar-discover-website.zip` وتقرير `discover-validation.json` يخصان النسخة السابقة من صفحة البروتوكول، وليسا نسخة الواجهة الجديدة.
