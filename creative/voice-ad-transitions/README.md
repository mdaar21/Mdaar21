# مدار v11 — انتقالات متنوعة مع صوت v10 نفسه

طلب المالك تنويع الانتقالات؛ النسخ السابقة حافظت على الصورة المتكررة أثناء تعديلات الصوت. هذه مراجعة للحركة عبر 13 انتقالًا بخمس عائلات متناسقة، مع نفس الهوية والشخصية الفارغة الوجه والأغلفة الأصلية والنص والكابشن وتوقيته.

- [الفيديو](https://mdaar21.github.io/Mdaar21/ad/varied/mdaar_tiktok_v11_transitions.mp4)
- [المشاهدة والتحميل](https://mdaar21.github.io/Mdaar21/ad/varied/)

| العائلة | العدد | الاستخدام |
| --- | --- | --- |
| كشف مائل باتجاهين | 2 | افتتاح المصادر وتغيير موضوع المتابعة |
| كشف من موضع بطاقة أو غلاف أو جهاز | 3 | الجدول، البرامج، وأدوات الموقع |
| كشف مع حركة كاميرا أفقية/رأسية | 5 | ربط النقاط والأدوات المتجاورة |
| انتقال تركيز ناعم | 2 | تجميع السؤال والختام |
| شاتر ذهبي | 1 | الكشف الرئيسي الأول لبروتوكول التحول |

`transitions.json` يحدد المواعيد والسبب التحريري والاتجاه لكل انتقال. الكاميرا على wrapper مستقل عن دخول العناصر، بإزاحة قصوى 128px ونهايات مستقرة. قُدّم دخول العناصر تحت الانتقال حتى لا يفتح الكشف على مساحة فارغة. عناوين انتقال التركيز تتسلم الدور دون تراكب، وعنوان الكشف الذهبي يدخل بعد مرور الشاتر. العنوان الأول ظاهر في أول إطار، ثم يستقر بحركة خفيفة. الكابشن والعلامة ثابتان فوق الانتقالات. لا دوائر بوابة أو glitch أو وميض أبيض أو شبكة خلايا.

**الصوت محفوظ:** `assets/final-mix.wav` مطابق لمزيج v10 المقبول، ويعيد `finish-video.py` استخدام تيار AAC من ملف v10 نفسه دون إعادة ترميز. تقرير `audio-unchanged.json` يتحقق من بصمة الحزم وتطابق عينات الصوت المفكوكة، لا من تشابه المستوى فقط. لا تغيير جديد للصوت أو المؤثرات أو موسيقى. لا تتغير الـ88 كلمة أو مجموعات الكابشن الـ25 أو توقيتها أو المدة نحو 39.1 ثانية.

## إعادة البناء

```sh
python3 build-film.py
npm run check
python3 verify-source.py
python3 verify-transitions.py
python3 record-motion.py
npx hyperframes@0.8.189 render --output renders/mdaar_transitions_render.mp4 --fps 60 --quality high --resolution portrait --crf 17 --workers 4
python3 finish-video.py
python3 verify-encoded.py
python3 verify-visual-change.py
```

مصدر الصورة `build-film.py` و`style.css`، والحركة `animate.js`، والخطة `transitions.json`. لا تعدّل HTML الناتج وحده. `timing.json` يحفظ خريطة التوقيت الأصلية فقط؛ إعدادات تنقية الصوت القديمة ليست مطبقة هنا. بعد التحقق تُنسخ MP4 وMP3 وSRT إلى `public/ad/varied/`، ثم يستخدم سكربت Pages الأساسي ويُنشر مجلد الإعلان الجديد وحده. يبقى التطبيق والواجهة والكتاب وزد والنسخ السابقة ومركز مدار كما كانت، ولا يدخل الإعلان تنقل المركز.

## الأدلة الفعلية

- `reports/check-final.json`: فحص HyperFrames الكامل. لا أخطاء تنفيذ أو تخطيط أو حركة أو تباين. تحذير إعادة استخدام أصل الغلاف الثابت مقصود، ومراجع بصريًا؛ ليس صورة جديدة مخترعة.
- `reports/source-browser.json`: المشاهد الـ14 والكابشن والوجوه الفارغة والمنطقة الآمنة ومنع ظهور العناوين مبكرًا والبحث العكسي.
- `reports/transitions-browser.json`: 91 لقطة مرتبة عبر الانتقالات، وفحص بداية/نهاية كل انتقال وثبات حالته بعد البحث العكسي. `transitions-a.jpg` و`transitions-b.jpg` شريطان زمنيّان تمت مراجعتهما.
- `reports/motion-playback.webm` و`motion-playback.json`: تسجيل صامت لتشغيل الحركة فعليًا في المتصفح، نافذة لكل انتقال. القفزات بين النوافذ مقصودة للاختبار؛ ليست مونتاج الإعلان. `playback-contact.jpg` يعرض تسلسلًا من هذا التسجيل. أداء متصفح المعاينة البرمجي ليس دليلًا على عرض 60fps في جميع الأجهزة؛ التصدير النهائي يأخذ عينات الخط الزمني نفسه عند 60fps.
- `reports/audio-unchanged.json`: الصوت الأخير نفسه ببياناته وعيناته، مع الكابشن الأصلي.
- `reports/encoded-validation.json` و`encoded-transition-comparison.json`: خصائص MP4 النهائي وتقديم رأسه ومقارنة صور الانتقالات المشفرة فعليًا مع v10. الاختلاف البكسلي يثبت أن الملف تغير، ولا يقيم الذوق.
- `reports/player-browser.json` و`live-verification.json` عند وجودهما: تشغيل وتحميل وسعي على الجوال والكمبيوتر، ثم مطابقة الملفات المنشورة للمخرجات المفحوصة.
