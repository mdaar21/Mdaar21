# مدار v9 — تعليق سعودي جديد

اختار المالك صراحةً «تعليق سعودي جديد» بدل تحسين التسجيل القديم. هذه إعادة تعليق بالصوت الرجالي السعودي `ar-SA-HamedNeural`، وليست طبقة صوت معدلة من المرفق أو نسخة مستنسخة من شخص. التعليق مولد من كتالوج Microsoft؛ لا ندعي تسجيلًا بشريًا. نصه حواري موجز، ونطقه معدّل كتابيًا لبعض الكلمات المحلية واسم مدار. الـ500 وصفة في الموقع، وبرامج التمارين والروابط في الدليل.

- [الفيديو](https://mdaar21.github.io/Mdaar21/ad/voice-saudi/mdaar_tiktok_v9_saudi.mp4)
- [المشاهدة والتحميل](https://mdaar21.github.io/Mdaar21/ad/voice-saudi/)
- [التعليق وحده](https://mdaar21.github.io/Mdaar21/ad/voice-saudi/voice-clean.mp3)

79 كلمة في 14 مشهدًا، ونحو 45.17 ثانية. نفس الشخصية الفارغة الوجه والشعار والأغلفة والألوان وحركات v7 المصححة، بتوقيت جديد يناسب التعليق. 23 مجموعة كابشن مبنية على حدود الكلمات الأصلية للمزود، و16 مؤثرًا قصيرًا من المكتبة السابقة، ولا موسيقى. لا ذكر للذكاء الاصطناعي في الإعلان. النسخ السابقة وروابطها محفوظة، ولم تتغير أسطح مدار الخمسة أو تنقل مركز مدار.

التعليق الأصلي الجديد دون EQ أو إزالة صدى أو ضوضاء أو تغيير طبقة أو فورمانت أو ضغط أو تمديد زمني. سرعة المزود +10% عند التوليد، ولا تسريع للفيديو الصوتي بعد التوليد. قُصَّت فقط الأطراف الصامتة والوقفات الطويلة خارج حدود الكلمات، بهوامش موثقة. تصحيح مستوى ثابت واحد؛ لم نرفع المستوى إلى v7 العالي. المزيج PCM المقاس −20.72 LUFS و−4.42 dBTP؛ مستوى AAC النهائي موثق في `reports/delivery-audio.json` عند اكتماله. هذه قياسات سلامة ومستوى، لا إثبات لذوق المشاهد أو إحساسه بالطبيعية.

## إعادة البناء

```sh
python3 -m pip install -r requirements.txt
python3 synthesize.py
python3 prepare-audio.py
python3 build-film.py
python3 export-captions.py
npm run check
python3 verify-source.py
npx hyperframes@0.8.189 snapshot --at 1.2,4.7,24.5,28,34.5,39.5,43.5
npx hyperframes@0.8.189 render --output renders/mdaar_tiktok_v9_saudi.mp4 --fps 60 --quality high --resolution portrait --crf 17 --workers 4
python3 verify-encoded.py
```

`script.json` هو النص المنطوق. `assets/voice/*.mp3` هي استجابات المزود الأصلية غير المعدلة، وملفات JSONL بجانبها حدود الكلمات الأصلية، وملفات الطلب تحفظ إعدادات الصوت وبصمة الطلب دون مفاتيح. توليدها يستخدم اتصال TLS متحققًا وحزمة الشهادات الموثوقة في البيئة، والوكيل الشبكي المهيأ إن وجد. خادم HeyGen وأي مفاتيح ElevenLabs/Gemini غير مهيأة هنا؛ اختير صوت سعودي متاح عبر كتالوج Microsoft لأن المالك اختار تعليقًا سعوديًا جديدًا، وKokoro المحلي لا يدعم العربية. لا ادعاء بترخيص استوديو أو استخدام صوت خاص. لا طلب مدفوع أو حساب جديد في هذه المهمة.

`prepare-audio.py` يحفظ خريطة القص وترجمة حدود الكلمات والتوقيت، ثم يمزج المؤثرات تحت الكلام. `build-film.py` و`animate.js` و`style.css` و`character.py` مصادر الصورة؛ HTML ناتج. الأغلفة والشعار والخطوط من أصول مدار الأصلية. تراخيص الخطوط وSFX محفوظة كما في المشروع السابق، و`media-provenance.jsonl` يسجل الأصول. لا تعتمد على توليد الصوت أثناء تشغيل الفيديو.

بعد التحقق، تُنسخ ملفات MP4 وMP3 وSRT إلى `public/ad/voice-saudi/`. يستخدم النشر سكربت Pages الأساسي، ويُنسخ مجلد الإعلان الجديد وحده إلى gh-pages؛ لا يُستبدل التطبيق المنشور ببناء غير مرتبط.

## الأدلة

- `reports/voice-provider.json` و`reports/voice-timeline.json`: المزود والاختيار والحدود الأصلية وخريطة كل مقطع. لا توقيت كلمات موزع بالتساوي.
- `reports/asr-check.json`: تفريغ مستقل محلي بواسطة Whisper medium متعدد اللغات للصوت النهائي، مع بصمة الملف. تعرّف على النص الأساسي واسم مدار والدليل والبرامج والروابط والاحتياج و500 وصفة والدعوة. توجد اختلافات إملائية مثل كتابة السين صادًا، فلا نعده تفريغًا بشريًا معتمدًا أو ضمانًا لطبيعية النبرة. الكابشن من بيانات المزود والنص المقصود، ولا يُستبدل بأخطاء التفريغ الآلي.
- `reports/source-browser.json`: المشاهد والكابشن والمنطقة الآمنة والوجوه الفارغة والسعي العكسي وعدم ظهور العناوين مبكرًا.
- `reports/check-final.json`: لا أخطاء تنفيذ/تخطيط/حركة. تحذيرات راجعتها: تكرار غلاف ثابت مقصود، صورة وصفة تتحرك داخل نافذة قص مقصودة، نص المشهد السابق تحجبه طبقة الانتقال، وإطار أول داكن لمدة دخول قصيرة موروثة. الصور في `reports/source-contact-sheet.jpg`، مع مراجعة الملف المشفر أيضًا بعد الإخراج.
- `reports/encoded-validation.json` و`reports/delivery-audio.json`: خصائص MP4 وربط AAC بالمزيج وتقديم رأس الملف والمستوى النهائي.
- `reports/player-browser.json` و`reports/live-verification.json` عند وجودهما: التشغيل والتحميل والجوال، ومطابقة الملف المنشور للنسخة المفحوصة.

لا اختبار استماع بشري مستقل ولا تصويت ELITE50 جديد أو نشر حملة تيك توك في هذه المهمة.
