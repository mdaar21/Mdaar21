# مصدر إعلان مدار الحالي

هذا هو مكان تعديل الإعلان داخل مستودع مدار. [العودة إلى مركز مدار](../../MDAAR_HUB.md).

النسخة الحالية v5: عشرون ثانية، عمودية، شخصية كرتونية بوجه خالٍ من الملامح، ومؤثرات صوتية فقط دون موسيقى. نُقل المصدر وأصوله إلى هذا المجلد كما هي؛ لم يتغير الفيديو خلال ترتيب المشروع.

- [المشاهدة والتحميل](https://mdaar21.github.io/Mdaar21/ad/character/).
- [ملفات النشر الحالية](../../public/ad/character/).
- [المواصفات وتقارير التحقق](../../docs/character-ad.md).
- [لقطة المصدر v5](../../docs/artifacts/mdaar-protocol-ad-v5-project.zip).

## مكان التعديل

| الملف | الغرض |
| --- | --- |
| `build-film.py` | بنية المشاهد، النصوص، مقاسات العناصر وأشكال الشخصية |
| `base-style.css` | الأنماط الأساسية؛ تجاوزات المشاهد داخل سكربت البناء |
| `animation-source.js` | الحركة، المفاصل، التوقيت والانتقالات |
| `create-effects.py` و`effects-cues.json` | مزج المؤثرات وتزامنها مع الحركة |
| `assets/` | الأغلفة والشعار والخط والمؤثرات المستخدمة |
| `index.html` | التكوين المولد؛ أعد توليده عند تغيير المصدر |
| `preview.html` | معاينة محلية مع التشغيل والتقديم والترجيع |
| `DESIGN.md` و`SCRIPT.md` و`STORYBOARD.md` | الهوية والنص وتوزيع المشاهد |

## التشغيل

من هذا المجلد، باستخدام HyperFrames بالإصدار المثبت في `package.json`:

```sh
python3 build-film.py
npm run check
npx --yes hyperframes@0.8.189 preview --background --no-open
```

لإعادة مزج المؤثرات الموجودة، شغّل `python3 create-effects.py`؛ يتطلب numpy وFFmpeg. لا يحتاج المزج مفتاح خدمة. لإنشاء MP4 شغّل `npm run render -- --output renders/mdaar-ad.mp4 --fps 30`، ثم راجع الفيديو قبل تحديث ملفات النشر.

آخر نسخ MP4 موجودة في `public/ad/character/` وليست مكررة في مجلد المصدر. بعد التعديل حدّث ملف النشر وتوثيقه وروابط النسخ الحالية في `MDAAR_HUB.md`. عند تغيير الواجهة المتحركة المنسوخة للنشر، انسخ التكوين إلى `composition.html` واضبط رابط المعاينة إلى هذا الاسم. اترك مسارات GitHub Pages نسبية.

شعار مدار وأغلفته الأصلية محفوظة. راجع `media-provenance.jsonl` و`FONT-LICENSE.txt` و`assets/sfx/CREDITS.md`. مرجع الفيديو الذي رفعه المالك غير مضمن. مصدر العمل الحالي هذا المجلد؛ مجلدات الفيديو المؤقتة خارج المستودع ونسخ الإعلانات القديمة مراجع تاريخية.
