# مدار — إعلان التسجيل v6

إعلان عمودي مبني على ملف `audio.mp3` الذي أرسله المالك في 26 أكتوبر 2026. التسجيل الأصلي محفوظ دون تغيير في المرفق؛ بصمته في `reports/audio-edit.json`، ولا تُستبدل هوية المتكلم أو يُولَّد كلام له.

- المصدر الصوتي 41.459 ثانية، وبعد قص الوقفات 37.598 ثانية، دون تسريع الكلام.
- 15 مشهداً، 29 مجموعة كابشن عربية، 88 كلمة. الشخصية الأصلية بلا ملامح، وأغلفة مدار وشعاره الأصلية، ولقطات فعلية من التطبيق.
- لا موسيقى؛ التعليق المرسل مع مؤثرات انتقال قصيرة أخفض منه بوضوح.
- التصدير المقصود 1080×1920، 30fps، H.264/AAC، MP4 قابل للتقديم والتحميل. الحقائق: 500 وصفة في الموقع وبرنامجا 4 و5 أيام. قيم التغذية تقديرية.

## التعديل وإعادة التصدير

`style.css` للتصميم، `character.py` للشخصية، `animate.js` للحركة، `words-final.json` للكابشن مع ربط وقته بالأصل، `build-film.py` لتوليد `index.html`. تعديل HTML الناتج وحده يضيع عند التوليد.

```sh
python3 build-film.py
python3 mix-audio.py
npm run check
python3 verify-source.py
npx hyperframes@0.8.189 snapshot --at 0.85,13.59,25.66,35.9
npx hyperframes@0.8.189 render --output renders/mdaar_tiktok_v6_1080p.mp4 --fps 30 --quality high --resolution portrait --crf 18 --workers 3
```

للصوت فقط: `assets/voice-clean.mp3`. لإعادة تنظيف المرفق الأصلي: `python3 process-audio.py /path/to/audio.mp3`. يحتاج Python وNumPy وFFmpeg. إعادة التصدير تعمل من المسارات المحلية والأصول المحفوظة ولا تحتاج خدمة خارجية أو مفتاحاً. فحص المتصفح يحتاج Playwright وChromium. مرّر `HYPERFRAMES_BROWSER_PATH` لمسار Chromium إذا لم يكتشفه CLI تلقائياً.

## التحقق وحدوده

- `reports/check-final.json`: فحص HyperFrames الكامل للتشغيل والتخطيط والحركة والتباين. تحذير إعادة استعمال صور الغلاف الثابتة في مشاهد مختلفة معروف؛ ليست مسارات صوت مكررة. الأصول الأكبر من حد الدمج الداخلي محفوظة محلياً ضمن المشروع وتُخدم أثناء التصدير.
- `reports/source-browser.json`: فحص المشاهد الخمسة عشر والكابشن كله، المساحات الآمنة، الوجوه الفارغة، واستقلال النتيجة عن ترتيب البحث الزمني.
- `reports/final-frames/` و`reports/final-changes/`: لقطات مصدر تمت معاينتها قبل التصدير. مجلد `reports/encoded-frames/` يخص معاينة ملف MP4 بعد التصدير عند وجوده.
- `reports/final-loudness.txt`: قياس الملف الممزوج قبل الترميز. `reports/audio-edit.json` يسجّل القصات والفلاتر؛ `reports/sound-mix.json` يسجّل المؤثرات. لا يُدّعى عزل استوديو مثالي أو إصلاح كل تشوه في المصدر.
- `reports/transcript-review.json`: تفريغ عربي متعدد اللغات، ثم إعادة تفريغ مركزة للمقاطع الملتبسة، مع تصحيح إملائي وربط التوقيت بالقصات. لا يُعرض التفريغ الأول غير المصحح ككابشن نهائي.
- `reports/app-captures.json`: لقطات التطبيق الفعلية بمدخلات مثال مصطنع، مع منع الشبكة الخارجية أثناء الالتقاط. المثال ليس ملف مستخدم حقيقي ولا توصية سعرات شخصية.

هذا إنتاج محلي قابل للمراجعة، لا حملة منشورة أو اختبار جمهور أو ضمان لقيمة بيع مالية. لا يُدّعى تصويت ELITE50 جديد في مهمة إنتاج هذا الفيديو؛ التصويت السابق يخص النص السابق فقط.
